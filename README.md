# ECG Arrhythmia Classifier

Proyecto académico desarrollado durante mi formación en Data Science.

## Objetivo
Explorar la clasificación automática de distintos tipos de latidos cardíacos a partir de señales ECG utilizando Deep Learning.

## Dataset
Se trabajó con el MIT-BIH Arrhythmia Dataset.

## Metodología
- Preparación y procesamiento de las señales ECG.
- Organización de los datos para entrenamiento y evaluación.
- Entrenamiento de un modelo basado en una red convolucional 1D.
- Evaluación del comportamiento del modelo sobre los datos disponibles.

## Herramientas
- Python
- Deep Learning
- CNN 1D
- Procesamiento de datos

## Resultados
Los resultados obtenidos se encuentran documentados en el código y archivos del proyecto.

## Limitaciones
Este proyecto fue desarrollado con fines académicos y de aprendizaje. No constituye una herramienta de diagnóstico médico.
